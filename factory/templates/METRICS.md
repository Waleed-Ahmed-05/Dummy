# Metrics

Copied by the `/poc` runner to the project root as `METRICS.md`. Written by the PRD stage; checked by the `measurement-editor`.

One row per figure a user of the POC reads. Every place in the code or UI that shows a figure cites its ID. All POC data is synthetic, so every figure is shown as **illustrative**.

| ID | Meaning (what a user takes it to say) | Formula | Denominator | Source (table / field / file) | Shown on |
|---|---|---|---|---|---|

- ID: `M-001`, `M-002`, …
- If the POC shows no figures, leave the table empty; the measurement editor then skips the run.
